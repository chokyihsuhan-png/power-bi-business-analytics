# Customer Segmentation via Clustering Analysis

An interactive Power BI dashboard designed to segment customers using clustering techniques based on their purchasing behavior. This project helps identify distinct customer groups to optimize targeted marketing strategies and maximize sales performance.

Key Project Features & Insights

Based on the dashboard analysis shown in the project view:

Customer Segmentation (Scatter Plot): Features a clear 4-cluster behavioral breakdown mapping Normalized Order Count against Normalized Avg Order Value (AOV) to separate high-frequency buyers from high-spending premium segments.
Revenue Breakdown by Segment:
Cluster 2 (Top Performer): Dominates the business revenue, driving 7.4M in Total Sales and accounting for 75% of the cumulative sales distribution.
Cluster 3 & Cluster 1: Represent the mid-tier growth opportunities, bringing in 1.4M and 0.8M respectively.
Cluster 4: Represents the long-tail segment with 0.2M in sales, reaching the 100% cumulative milestone.
Granular Customer Profiles: Includes an interactive matrix detailing CustomerID, Total Sales, Avg Order Value, and individual Order Count per cluster for precise customer-level targeting.

Tools & Technologies Used
Power BI Service / Desktop: For interactive data visualization, cluster segment mapping, and cumulative Pareto analytics.
Data Analytics: Behavioral customer segmentation, feature normalization, and sales distribution modeling.
